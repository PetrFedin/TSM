# TSM

Аудитируемая аналитика ассортимента мужских товаров на tsum.ru.

Материалы разделяют:

- наблюдаемые факты и серверные счётчики сайта;
- расчётные метрики с явными формулами;
- аналитические гипотезы и сценарии, требующие проверки продажами, остатками и маржинальностью.

Первый аналитический пакет формируется в отдельной ветке с pull request.
